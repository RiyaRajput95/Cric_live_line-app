# 🏏 Cricket Live Line

A modern **Flutter cricket live line application** built with **Flutter and Dart**.

The app provides cricket match information including **live scores, match updates, scorecards, teams, players, and other match details** through a clean and user-friendly mobile interface.

## ✨ Features

* 🏏 Live Cricket Scores
* 🔴 Live Match Updates
* 📊 Detailed Scorecard
* 👥 Team Information
* 🧑‍💻 Player Details
* 🏆 Match Information
* 📈 Runs, Wickets & Overs
* ⏱️ Match Status
* 🏟️ Match Details
* 🔄 Updated Match Information
* 📱 Clean and Modern UI
* 🧭 Easy Navigation Between Screens

## 🛠️ Tech Stack

* **Flutter**
* **Dart**
* **Material Design**
* **REST API**
* **JSON**

> REST API and JSON are included if the application retrieves cricket data from an API.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Flutter SDK
* Dart SDK
* Android Studio
* Android SDK
* JDK
* Android device or emulator

### Clone the Repository

git clone https://github.com/RiyaRajput95/CricketLiveLine.git
### Open the Project

Open the cloned project folder in **Android Studio** or **Visual Studio Code**.

### Install Dependencies

Run:
flutter pub get
### Run the Application

Connect an Android device or start an Android emulator, then run:
flutter run
You can also run the application using the **Run ▶** button in Android Studio.

Cricket Live Line was created to demonstrate **Flutter mobile application development**, modern UI design, screen navigation, and cricket match data presentation.
